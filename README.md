# Number Guessing Game

Build #01 of my 12-month AI Engineer journey.

A Python game where the player guesses a secret number between 1 and 100.

## Features

- Random secret number between 1 and 100
- Too high / too low hints
- Attempts counter
- Invalid input and range validation
- Replay with yes/no validation

## How to Run

1. Install Python 3.
2. Open a terminal in the project folder.
3. Run:
   `python bulid01.py`

## What I Practiced

- Generating random numbers
- Taking input and converting it to integers
- Using conditions and nested loops
- Counting attempts
- Handling ValueError
- Using break, continue, strip and lower

## Bugs I Fixed

- Conditions outside the guessing loop
- Range check running before input
- Incorrect break placement stopping replay
- A commented input line causing an infinite loop

## My Experience

The hardest part for me was understanding indentation and nested loops.
